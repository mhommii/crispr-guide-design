# Third-party data

The MIT licence in [`LICENSE`](LICENSE) covers the code and documentation in
this repository. It does **not** cover data obtained from third parties, which
keeps its own terms and citation requirements:

| Source | Terms |
|---|---|
| NCBI Gene, RefSeq, Entrez | [NCBI Website and Data Usage Policies](https://www.ncbi.nlm.nih.gov/home/about/policies/) |
| Ensembl | [Ensembl terms of use](https://www.ensembl.org/info/about/legal/disclaimer.html) |
| UCSC Genome Browser | [UCSC conditions of use](https://genome.ucsc.edu/conditions.html) |
| TCGA / MC3 somatic mutation calls | [NIH Genomic Data Sharing Policy](https://sharing.nih.gov/genomic-data-sharing-policy) |

Cite the original publications listed in the README when reusing any results
derived from these sources.
